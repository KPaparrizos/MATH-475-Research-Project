The file uc_conj_verify.c contains the code for verifying the conjectures on m <= 6.
The files full_families.csv and full_summary.csv contain the computational results for 
all near miss families and a summary for families of each size respectively. The 
full_log.txt file is the log for the run of uc_conj_verify.c. The file uc_classify.c 
classifies near-miss families. The nm6_classes.csv file contains information about near-miss 
families for m = 6. The nm6.log file is the log for the run of uc_classify.c.
